# Results Directory

All output files from the pipeline are written here.

| File / Folder | Generated by | Description |
|---|---|---|
| `baseline_results.csv` | `src/baseline_models.py` | Accuracy, F1, Precision, Recall for LR / NB / SVM |
| `transformer_results.csv` | `src/transformer_models.py` | Same metrics for XLM-RoBERTa and AfriBERTa |
| `final_comparison.csv` | `src/evaluate.py` | All models merged, sorted by F1 |
| `error_analysis.txt` | `src/evaluate.py` | Qualitative error analysis report |
| `figures/` | Multiple scripts | All `.png` charts |

## Figures

| Filename | Description |
|---|---|
| `label_distribution.png` | Class balance bar/pie chart |
| `baseline_comparison.png` | F1 comparison across baselines |
| `confusion_logistic_regression.png` | Confusion matrix |
| `confusion_naive_bayes.png` | Confusion matrix |
| `confusion_linear_svm.png` | Confusion matrix |
| `confusion_xlm_roberta.png` | Confusion matrix |
| `confusion_afriberta.png` | Confusion matrix |
| `final_comparison.png` | All models, all metrics |
| `f1_ranked.png` | Horizontal bar chart ranked by F1 |

> Results files and figures are generated by running the pipeline — they are **not stored in Git**.
> Re-generate by running `python src/evaluate.py` after completing baseline and transformer training.
